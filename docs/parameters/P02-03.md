## What it does

Speed feedforward sends the rate of the position command directly to the speed loop. Then the position loop corrects only the remaining error. The value is the part of the command rate that goes through, in %.

At 0 %, all of the speed command comes from the position loop. The motor must lag behind the command before it moves. At 100 %, the full commanded speed goes to the speed loop.

## Effect

- At a constant speed, the following error is (1 − FF) × speed ÷ P02-00. At 100 %, it is approximately zero.
- A higher value also gives a smaller following error during acceleration.
- Too high a value causes overshoot at the end of a move. The motor goes past the target and comes back.
- With step and direction input, the command rate is not smooth. A high value passes this roughness to the motor. The filter P02-04 smooths it.

## How to set it

1. Tune the speed loop and the position loop first.
2. Increase the feedforward in steps of 10 %. Look at the following error and the overshoot at the end of each move.
3. Stop at the value where overshoot starts. Then decrease it by 10 %.
4. If the motor becomes rough or noisy at constant speed, increase P02-04.

In the auto-tuning mode 2 (P01-02), the drive fixes this value at 30 %.

On a machine with several axes, use the same feedforward on all axes that move together. Then the following errors match, and curves keep their shape.
