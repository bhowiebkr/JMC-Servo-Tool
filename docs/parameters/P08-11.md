## What it does

The adaptive notch finds a mechanical resonance while the motor runs. Then it sets a notch filter to remove it. This parameter selects what the adaptive notch does.

| Mode | What the drive does |
|---|---|
| 0 | Off. Notches 3 and 4 keep their values, and you can set them by hand. |
| 1 | The drive sets notch 3 (P08-36 to P08-38). You cannot set notch 3 by hand. |
| 2 | The drive sets notch 3 and notch 4 (P08-39 to P08-41). |
| 3 | The drive finds the resonance frequency, but it does not set a notch. |
| 4 | The drive sets notches 3 and 4 back to the factory values. |

The adaptive notch does not use notches 1 and 2. You set those by hand.

## How to set it

1. Set mode 1.
2. Run the moves that cause the vibration. The drive sets notch 3.
3. When the vibration stops, set mode 0. Notch 3 keeps the values that the drive found.

If the adaptive notch sets a wrong notch, set mode 4 to remove it.

The sensitivity P08-13 sets how small a vibration the adaptive notch reacts to.
