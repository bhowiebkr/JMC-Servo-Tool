## In plain words

The drive must know how many pulses the other gantry motor sends for one turn. Only then can it compare the two motor positions correctly.

## How it works

Set this to the number of feedback pulses that the other motor gives for each turn. The factory value is 10000. The value must be larger than 128, otherwise the drive gives the alarm AL.105.

The manual says that a change applies after a power cycle.

## On your machine

This matters only with gantry synchronization on (P03-50 = 1). Change it only with the servo off.
