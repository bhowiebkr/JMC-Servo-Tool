## What it does

This is a low-pass filter on the speed feedback. The drive calculates the motor speed from the encoder. This measured speed has noise. The filter smooths it before the speed loop uses it.

The value is the time constant of the filter, in ms. 0 turns the filter off.

## Effect

- A higher value gives less noise in the torque command. The motor is quieter.
- A higher value also adds delay to the speed loop. With more delay, the speed loop gain (P02-10) becomes unstable at a lower value.

## How to set it

Start at the factory value, 0.80 ms. If the motor makes a high-pitched noise, increase this value or the torque command filter (P08-20). Keep it as low as possible, so that the speed loop gain can stay high.
