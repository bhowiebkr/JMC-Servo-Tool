## In plain words

A controller that sends 0 V can really send a few millivolts. In torque mode, the motor then pushes a little when it should not push at all. This offset corrects that small error.

## How it works

The unit is volts, and the range is −10 V to +10 V. The factory value is 0 V. The drive corrects the input voltage by this value before it calculates the torque.

## On your machine

A CNC axis runs in position mode and does not use the analog input.
