## What it does

The speed loop has a proportional part and an integral part. The integral part adds up the speed error over time. It removes a constant speed error. It also holds the position against a constant load, for example gravity or friction.

The integral time sets how fast the integral part acts. A shorter time gives a stronger integral action. The maximum, 1000.0 ms, gives almost no integral action.

## Effect

- A shorter time removes speed and position error faster after a load change.
- Too short a time causes overshoot and a slow oscillation. With a high speed loop gain, it causes vibration.
- A longer time gives a softer response with less overshoot. Under a constant load, the axis keeps a small position error.

## How to set it

A common start value in ms is 4000 ÷ (2π × P02-10). For P02-10 = 27.0 Hz, this is approximately 24 ms.

1. Set the speed loop gain (P02-10) first.
2. Start with the value from the rule above.
3. Decrease the time in small steps. Look at the overshoot after a move and the recovery after a load change.
4. Stop when overshoot or oscillation starts. Then go back one step.

The factory value is 10.0 ms. This is shorter than the rule gives for the factory gain of 27.0 Hz.

## Gain set 2

P02-14 is the integral time of gain set 2. Its factory value is 1000.0 ms, so gain set 2 has almost no integral action.
