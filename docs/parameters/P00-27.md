## In plain words

All devices on a CAN bus must use the same bit rate. A higher rate gives faster messages, but the cable must then be shorter. At 1 Mbit/s, a CAN bus can be approximately 40 m long. At 125 kbit/s, it can be approximately 500 m long.

## How it works

The drive uses the rate only if it has a CAN port and the bus is in use. The value 1 is listed as 120 kbit/s in the drive data. This is not a standard rate, so it is marked as unverified.

## On your machine

A machine that LinuxCNC controls with step and direction does not use CAN. Leave this value as it is.
