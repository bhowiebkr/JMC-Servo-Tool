## In plain words

This is the bottom number of the second gear ratio. The top number is P03-13. A digital input with function 6 selects this second ratio.

## How it works

The second ratio works like the first one (P03-10 ÷ P03-11). It applies only when the selection input is on.

## On your machine

LinuxCNC does not need a second gear ratio. Keep the factory value 1.
