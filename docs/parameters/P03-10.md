## In plain words

The electronic gear ratio decides how far the motor turns for each command pulse. This parameter is the top number of the ratio. The bottom number is P03-11. Use the ratio when a simple pulse count for each turn (P03-09) is not exact enough.

## How it works

The ratio applies only when P03-09 is 0. Each command pulse then moves the motor by this many encoder counts:

numerator ÷ denominator = encoder counts for one turn ÷ command pulses for one turn

An absolute encoder gives 131072 counts in each turn. An incremental encoder gives 4 counts for each line.

A change applies after a power cycle.

## Example

A 5 mm ball screw, and one pulse must move the axis 0.001 mm. So one motor turn needs 5000 pulses.

The ratio is 131072 ÷ 5000. This reduces to 16384 ÷ 625. Set this parameter to 16384 and P03-11 to 625.

If the numerator is larger than 65535, use P03-12 for the high part.

## Watch out

A ratio that the drive cannot use gives the alarm AL.105.
