## What it does

JMC names this parameter the torque command filter for low speed. It works the same as the torque command filter (P08-20). The value is the time constant, in ms.

The drive documentation does not say at which speed the drive uses this filter. It also does not say how the drive changes between this filter and P08-20.

## How to set it

Keep it the same as P08-20. Change it only if the motor makes noise at low speed or at a stop, and not at higher speed.
