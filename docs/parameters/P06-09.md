## In plain words

The drive has eight digital inputs, DI1 to DI8. None of them has a fixed job. You give each input a job, its function, from the list below. This parameter sets the function of DI5. The factory function is external forward torque limit.

## How it works

P06-08 sets which signal counts as active. While the input is active, its function is on.

| Value | Function | What it does |
|---|---|---|
| 0 | Not used | The input does nothing. |
| 1 | Servo on | Turns on the current to the motor. Without it, the motor is free and holds nothing. |
| 2 | Alarm reset | Clears an alarm after you repair the cause. Some alarms clear only with a power cycle. |
| 3 | Forward limit | A limit switch at the forward end of travel. The motor stops, and then it accepts only reverse moves. P01-10 sets how it stops. |
| 4 | Reverse limit | A limit switch at the reverse end of travel. It works in the same way as the forward limit. |
| 5 | Control mode switch | Changes between the two modes of a mixed control mode (P01-01 = 3, 4 or 5). |
| 6 | Electronic gear select | Changes from electronic gear 1 to electronic gear 2 (P03-13 and P03-14). |
| 7 | External forward torque limit | Changes the forward torque limit from P05-10 to the lower limit P05-12. |
| 8 | External reverse torque limit | Changes the reverse torque limit from P05-11 to the lower limit P05-13. |
| 9 | Gain switch | Changes to gain set 2, when P02-30 is 2. |
| 10 | Zero clamp | Locks the motor when the speed command is almost zero. See P04-03. |
| 11 | Pulse inhibit | The drive ignores the step pulses, and the motor holds its position. |
| 12 | Absolute data request | Asks the drive for the absolute position of the encoder. The manual does not say how the drive sends it. |
| 13 | Internal speed select 1 | Together with functions 14 and 15, selects one of the eight internal speeds P04-30 to P04-37. |
| 14 | Internal speed select 2 | See function 13. |
| 15 | Internal speed select 3 | See function 13. |
| 16 | Position command clear | Clears the following error. The steps that the motor has not yet followed are lost. |
| 17 | Magnetic pole detection | Starts a measurement of the magnet position in the motor. A standard motor with its own encoder does not need it. |
| 18 | Pulse multiplier switch | Changes the scale of the step pulses to a second value. The manual does not name the setting for that value. |
| 19 | Gantry sync enable | Switches on the gantry synchronization of two motors. See P03-50. |
| 20 | Gantry alignment clear | Clears the position difference between the two gantry motors. |
| 21 | Home switch | The home switch for the homing function of the drive. See P03-60. |
| 22 | Homing start | Starts the homing function of the drive. |
| 23 | Speed analog direction | Turns around the direction of the analog speed command. |
| 24 | Torque analog direction | Turns around the direction of the analog torque command. |

Do not give the same function to two inputs.

The change takes effect after a power cycle. Save it to EEPROM, then turn the drive off and on.

## On your machine

If no wire connects to this input, it has no effect, and P05-10 limits the torque all the time.
