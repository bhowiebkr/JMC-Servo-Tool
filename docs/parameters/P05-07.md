## In plain words

The real torque of a motor can differ a little from what the drive calculates. This factor corrects the difference, so that a torque command gives the true torque.

## How it works

The unit is percent. The range is 50 % to 150 %.

For example, a command of 1.27 N·m gives only 1 N·m on a torque meter. 1.27 ÷ 1 = 127 %, so set 127.

The factory value 0 is outside the range. The drive probably reads it as "no correction".

## On your machine

You need a torque meter to set this correctly. Most machines do not need it. Leave it at the factory value.
