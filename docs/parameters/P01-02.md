## In plain words

A servo drive has many gains. A gain is a number that sets how hard the drive reacts to an error. To set each gain by hand takes skill and time. So the drive can set most of them for you, from one stiffness level (P01-03). This parameter selects who sets the gains: you or the drive.

## How it works

This parameter selects who sets the loop gains: you or the drive. The factory value is 1. In this mode, the drive sets most gains itself.

| Mode | Gains that the drive sets from P01-03 | Other values |
|---|---|---|
| 0 | None. You set all gains. | You set all values. |
| 1 | P02-00, P02-01, P02-10, P02-11, P02-13, P02-14 and P08-20 | You set P02-03 and P02-04. |
| 2 | The same gains as mode 1 | P02-03 is fixed at 30 %. P02-04 is fixed at 0.50 ms. |
| 3 | P02-00, P02-01, P02-10, P02-11 and P02-13 | P08-20 comes from P01-04. P02-14 is fixed at 100. You set P02-03 and P02-04. |

## What a change does

- In modes 1 to 3, a value that you write to one of these gains has no effect. The drive uses the values for the stiffness level.
- In mode 0, the drive uses the values that you write to P02-00 to P02-15 and P08-20.

This is important when you tune by hand. With the factory mode 1, changes to P02-10 or P02-00 do nothing.

## How to set it

1. Start in mode 1. Set the load inertia ratio (P01-04) first.
2. Change the stiffness level (P01-03) one step at a time. Find the highest level that stays quiet.
3. For full control, set mode 0. Then tune P02-10, P02-11 and P02-00 by hand.

## On your machine

Keep mode 1 while you learn. Set the load inertia ratio (P01-04) first, and then find a good stiffness level (P01-03). This gives good results on most CNC axes.

Change to mode 0 only when you want to tune each gain yourself. In mode 0, the drive uses the values in the P02 parameters as they are. So read them, and check that they make sense, before you run the axis.
