## In plain words

This is the bottom number of the electronic gear ratio. The top number is P03-10. Together they decide how far the motor turns for each command pulse.

## How it works

The ratio applies only when P03-09 is 0. A larger denominator makes each pulse move the motor a shorter distance.

A change applies after a power cycle.

## Example

An incremental encoder has 2500 lines, so it gives 10000 counts in each turn. You want 3200 pulses for each turn. The ratio is 10000 ÷ 3200, which reduces to 25 ÷ 8. Set P03-10 to 25 and this parameter to 8.
