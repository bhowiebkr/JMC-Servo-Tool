## In plain words

A servo drive can follow three kinds of command. "Go to this position", "turn at this speed" or "push with this force". The control mode selects which kind of command the drive follows.

## How it works

| Mode | The drive controls | Command from |
|---|---|---|
| 0 Position | The position of the shaft | Step and direction pulses, see P03-00 |
| 1 Speed | The speed of the shaft | An analog voltage or internal speeds, see P04-00 |
| 2 Torque | The force on the shaft | An analog voltage or a set value, see P05-00 |
| 3, 4, 5 | Two of these modes | A digital input with function 5 selects the mode |
| 6 | A special mode | See below |

In position mode, the drive also controls the speed and the torque. But it uses them only as steps on the way to the commanded position.

Mode 6 is a special mode. The drive table calls it full closed loop. The manual of this drive calls it a servo screwdriver mode. Do not use it on a CNC axis.

## On your machine

A CNC axis that LinuxCNC drives with step and direction uses mode 0. This is the factory setting. Change the mode only with the servo off.

## Watch out

In speed or torque mode, the drive ignores the step pulses. If you change the mode by mistake, the axis no longer follows LinuxCNC.
