## In plain words

The drive can keep two complete sets of gains and change between them. One set can suit moves, and the other set can suit a stop. This is the position loop gain of gain set 2. Like P02-00, it sets how hard the drive pulls the motor toward its target.

## How it works

This is the position loop gain of gain set 2. It works the same as P02-00, the gain of gain set 1. The drive uses gain set 2 when the gain switching condition (P02-30) is true.

The factory value is 57.0 1/s, a little higher than P02-00. With the factory gain switching mode 7, the drive uses gain set 2 while a position command comes in. It uses gain set 1 when the motor stops.

## The changeover

When the drive changes to gain set 2, the position gain changes smoothly from P02-00 to P02-01. The time for this change is P02-34.

In the auto-tuning modes 1 to 3 (P01-02), the drive sets this gain from the stiffness level.

## How to set it

Set it the same way as P02-00. With the factory settings, gain set 2 is active during moves. So look at the following error during a move.

## On your machine

With the factory settings, this gain is active during every move. So it controls how closely the axis follows the path while it cuts.
