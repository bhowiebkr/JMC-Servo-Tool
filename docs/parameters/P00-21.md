## In plain words

Two devices on a serial link must talk at the same speed. Two people must also speak at the same pace to understand each other. The baud rate is this speed, in bits per second.

## How it works

The RS232 port connects the drive to a PC. The PC software and the drive must use the same rate. If the rates are different, the PC receives only noise, and the link stops.

## On your machine

This tool does not write this parameter. If it changed the rate, it would lose its own link to the drive at the next power-on. The only way to repair the link would be the front panel.

If you need a different rate, change it on the front panel. Then set the same rate in the connection settings of this tool.

## Factory value

The table shows 0 (9600 bit/s) as the factory value, because JMC's PC tool gives this value. The drive manual gives 2 (57600 bit/s). One of the two is wrong.

You do not have to know the value. **Find settings** in the window, or `jmc probe`, tries each rate and finds the rate that the drive uses.
