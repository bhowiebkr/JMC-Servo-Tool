## In plain words

The zero clamp locks the motor when the speed command is almost zero. This parameter decides what "almost zero" means.

## How it works

The unit is rpm. The factory value is 30 rpm. When the speed command is below this value, and the other conditions of P04-03 are true, the drive locks the motor.

## On your machine

A CNC axis runs in position mode, so this setting has no effect there.
