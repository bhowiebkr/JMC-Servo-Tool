## In plain words

When the speed command jumps, a normal speed loop reacts at once with a big push. This gives a fast response, but it can overshoot. PDFF lets you soften the reaction to the command, while the reaction to a load stays strong. It is like a calm driver who speeds up gently, but still holds the speed on a hill.

## How it works

PDFF means pseudo-derivative feedback with feedforward. This factor sets where the proportional part of the speed loop acts.

- At 100 %, the proportional part acts on the speed error. The speed loop is a normal PI controller. This gives the fastest response to a command.
- At 0 %, the proportional part acts on the measured speed only. A change of the speed command must go through the integral part first.
- Values between 0 and 100 % mix the two.

## What a change does

- A lower value gives a slower response to the command, with less overshoot.
- The response to a load change stays almost the same. So a lower value can let you use higher gains without overshoot on moves.
- A CNC axis must follow a path. A slow command response gives a large following error.

## How to set it

Keep it at 100 % for most machines. If the speed loop overshoots after you set P02-10 and P02-11, try lower values in steps of 10 %. Look at the following error at the same time.

## Gain set 2

P02-15 is the PDFF factor of gain set 2.

## On your machine

A CNC axis must follow its path closely, so a slow response to the command is a problem. Keep 100 % unless the axis overshoots and the other gains cannot fix it.
