## In plain words

This is the most important setting for a step and direction machine. It decides how far the motor turns for each pulse. It works like a gearbox, but in software: the electronic gear.

## How it works

The value is the number of command pulses for one motor turn. The factory value is 10000.

- More pulses for each turn give finer steps.
- But the controller must send more pulses each second for the same speed.

If you set 0, the drive uses the gear ratio P03-10 ÷ P03-11 instead. Use the ratio when one turn is not a whole number of pulses.

A change applies after a power cycle.

## Example

Your ball screw moves 5 mm for each turn, and you want one pulse to move the axis 0.001 mm.

1. One turn is 5 mm ÷ 0.001 mm = 5000 pulses. Set this value to 5000.
2. In LinuxCNC, the scale is then 1000 steps for each mm.
3. At 3000 rpm, the pulse rate is 50 turns × 5000 = 250 kHz.

## Watch out

The scale in LinuxCNC must match this value. If they do not match, every distance is wrong. Check the pulse rate at full speed against the limit of the input (see P03-02).
