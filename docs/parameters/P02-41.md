## In plain words

This is the level at which the speed loop changes from PI control to P control. P02-40 selects the signal that the drive compares with this level.

## How it works

The unit depends on the signal in P02-40.

| Signal | Scale |
|---|---|
| Torque | 1000 = 25 % of rated torque |
| Speed | 1000 = 200 rpm |
| Position error | 131072 = one motor turn |

The factory value 10000 with the torque signal means 250 % of rated torque.

## When to change it

Keep the factory value. A lower value turns off the integral part more often. This can reduce overshoot, but the axis then holds its position less firmly against a load.
