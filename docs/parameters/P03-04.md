## In plain words

Electrical noise can make short spikes on the pulse wires. The drive can count a spike as a step, and the axis then drifts away from its correct position. This filter ignores pulses that are too short to be real steps.

## How it works

The filter ignores any pulse that is shorter than its time. So a longer time rejects more noise. But it also rejects real pulses if they are short, so it limits the fastest pulse rate.

| Value | Filter time |
|---|---|
| 0 | 0.1 µs |
| 1 | 0.4 µs |
| 2 | 0.8 µs |
| 3 | 1.6 µs |

The manual of this drive lists only two of these values: 0.1 µs and 1.6 µs.

## On your machine

LinuxCNC has two step timings: the step length and the step space. Both must be clearly longer than the filter time. With a filter of 1.6 µs, use at least 2000 ns for both.

If the axis loses position slowly, and the following error alarm does not trip, noise on the pulse wires is a likely cause. First check the cable shield and the ground. Then try a longer filter time.
