## In plain words

A drive must know the motor that it drives, just as a charger must know the battery that it charges. The motor code tells the drive where to find this information.

## How it works

- **2000**: the motor has an absolute encoder with a small memory. The motor data is stored in this memory. At power-on, the drive reads it, so the motor tells the drive what it is.
- **0**: the drive does not read the data from the motor. Then the drive uses the values in P00-01 to P00-17.

Most JMC motors with an absolute encoder use 2000. The factory sets the code for the motor that it sells with the drive.

## When to change it

Do not change it if the drive and the motor came together. Change it only if you connect a different motor, and then only with the data of that motor.

## Watch out

Wrong motor data can make the motor turn the wrong way, get too hot or run out of control. The drive uses the new value only after a power cycle.
