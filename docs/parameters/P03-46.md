## In plain words

With digital position commands, the drive plans each move itself. This parameter sets the top speed of those moves.

## How it works

The unit is rpm. The factory value is 1000 rpm. This applies only when P03-00 is 1. With pulse commands, the controller sets the speed with the pulse rate.

## On your machine

LinuxCNC with step and direction does not use digital position commands. This setting has no effect there.
