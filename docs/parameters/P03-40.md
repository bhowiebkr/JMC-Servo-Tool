## In plain words

The encoder output on connector CN1 can repeat one of several signals. Another device can then read it. This parameter selects which signal the drive sends out.

## How it works

| Value | The output repeats |
|---|---|
| 0 | The pulse command. The output stops at an alarm. |
| 1 | The motor encoder. This is the factory setting. |
| 2 | The pulse command. |
| 3 | The linear scale. |

Value 0 can pass the pulses on to a second drive. Then the second axis also stops if the first drive has an alarm.

## On your machine

LinuxCNC with step and direction does not need the encoder output. Keep the factory value 1. Change it only with the servo off.
