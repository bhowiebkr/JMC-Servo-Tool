## In plain words

After the fast search, the axis moves slowly to the exact home point. A slow approach makes the home position repeatable. This parameter is that slow speed.

## How it works

The factory value is 10. The unit is not documented. It is probably rpm.

## On your machine

This applies only to the homing function in the drive. LinuxCNC does the homing itself, so this setting has no effect there.
