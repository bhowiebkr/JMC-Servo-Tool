## In plain words

In torque mode, the motor pushes with a set force, and the speed is whatever the load allows. If the load disappears, for example when a belt breaks, nothing holds the motor back. It accelerates to full speed. This limit stops that runaway.

## How it works

The unit is rpm. The factory value is 1500 rpm. The limit applies in torque mode when P05-00 is 0 or 1.

## On your machine

A CNC axis runs in position mode, so this setting has no effect there. In torque mode, set it to the lowest speed that the job needs.
