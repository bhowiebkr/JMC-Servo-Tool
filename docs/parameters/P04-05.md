## In plain words

A motor that turns much faster than it should is a sign that something is wrong. This alarm level is a safety net. If the motor goes faster than this speed, the drive stops it at once.

## How it works

The unit is rpm. If the motor speed goes above this value, the drive stops with AL.420. This works in every control mode. The factory value is 6400 rpm.

A correct position command never asks for such a speed. So the alarm catches a fault. Examples are a noisy step signal, a wrong gear setting or a motor that runs out of control.

## On your machine

Set it a little above the fastest speed that your machine uses. For example, if your rapid moves need 3000 rpm, 3500 rpm is a good value. Then a fault stops the axis before it reaches a dangerous speed.

## Example

A 5 mm ball screw at 3000 rpm moves 15 000 mm each minute. If LinuxCNC never moves faster than this, a motor speed of 4000 rpm can only come from a fault.
