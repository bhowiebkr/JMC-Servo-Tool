## In plain words

All devices on a Modbus line must talk at the same speed. The baud rate is this speed, in bits per second. A higher rate is faster, but long cables or electrical noise can then cause errors.

## How it works

At 9600 bit/s, one character takes approximately 1 ms. A short Modbus message has approximately 8 characters. So the default rate is enough to read a few parameters each second, but slow for large reads.

The value 7 is listed as 25600 bit/s in the drive data. This is not a standard rate, so it is marked as unverified.

## On your machine

This tool does not write this parameter, because a wrong rate cuts off the link. Change it on the front panel if you need to. Then set the same rate in this tool.
