## In plain words

The drive has five digital outputs, DO1 to DO5. They tell the controller what the drive is doing. You give each output a job, its function, from the list below. This parameter sets the function of DO1. The factory function is servo ready.

## How it works

P06-20 sets if the output conducts or blocks while its function is active.

| Value | Function | What it does |
|---|---|---|
| 0 | Not used | The output is never active. |
| 1 | Alarm | Active when the drive has stopped with an alarm. |
| 2 | Holding brake release | Active when the holding brake in the motor must open. P01-30 sets the timing. |
| 3 | Servo ready | Active when the main power is on and the drive has no alarm. The drive is then ready for servo on. |
| 4 | In position | Active when the axis has reached its target, within the range P03-06. P03-05 sets the condition. |
| 5 | Near position | Active when the axis is close to its target, a little before the in-position output. The drive data does not name its range. |
| 6 | Speed match | Active when the motor speed is within P04-12 of the speed command. |
| 7 | Zero speed | Active when the motor speed is below P04-10. |
| 8 | Torque limit active | Active when the motor pushes at its torque limit. P05-06 sets a delay. |
| 9 | Speed limit active | Active when the motor runs at its speed limit, for example P05-02 in torque mode. |
| 10 | Warning | Active when the drive gives a warning. A warning comes before an alarm, for example when the motor gets close to overload. |
| 11 | Pulse multiplier active | Active while the second scale of the step pulses applies (input function 18). |
| 12 | Homing complete | Active when the homing function of the drive has finished. |
| 13 | Electrical homing complete | Active when the electrical homing has finished. The manual does not explain how it differs from function 12. |

The change takes effect after a power cycle. Save it to EEPROM, then turn the drive off and on.

## On your machine

LinuxCNC can wait for servo ready before it enables the axis. Many simple machines do not use it.
