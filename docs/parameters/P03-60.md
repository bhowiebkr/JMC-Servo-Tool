## In plain words

Homing finds a known reference point on an axis after power-on. The drive has its own homing function. It can move the axis to a home switch without help from the controller. This parameter controls that function.

## How it works

The values 0 to 6 are not documented. 0 is the factory setting and is probably off.

Two digital input functions belong to homing. Function 21 is the home switch, and function 22 starts the homing. If homing takes longer than P03-68, the drive stops with AL.551.

## On your machine

LinuxCNC does the homing itself, with home switches that connect to LinuxCNC. Keep 0.
