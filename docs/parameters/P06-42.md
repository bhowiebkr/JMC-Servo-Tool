## In plain words

An analog signal is never perfect. A controller that sends 0 V can really send a few millivolts. Then the motor creeps slowly when it should stand still. This offset corrects that small error.

## How it works

The unit is volts, and the range is −10 V to +10 V. The factory value is 0 V. The drive corrects the input voltage by this value before it calculates the speed.

## How to set it

1. Set the controller to a zero speed command.
2. Look at how fast the motor creeps, and in which direction.
3. Change the offset in small steps until the motor stands still.

If the creep gets faster, change the sign of the offset.

## On your machine

A CNC axis runs in position mode and does not use the analog input.
