## In plain words

With digital position commands, a controller sends target positions as numbers. A new target can arrive while the motor is still moving to the last one. This parameter selects what the drive does then: change course at once, or finish the current move first.

## How it works

- **0 No buffer**: the new target replaces the current one at once.
- **1 Buffer**: the drive finishes the current move, and then starts the new one.

This applies only when P03-00 is 1.

## On your machine

LinuxCNC with step and direction does not use digital position commands. This setting has no effect there.
