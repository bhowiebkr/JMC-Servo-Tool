## In plain words

The drive needs to know how heavy the load is, compared to the motor. This is the load inertia ratio P01-04. The drive can measure the ratio itself. This parameter turns that measurement on or off.

## How it works

- **0 On**: this is the factory setting.
- **1 Off**

Note that 0 is on. The manual does not say if this setting also controls a continuous estimate during normal running. The test run itself starts from the front panel, with AF_J-L. P08-02 to P08-05 set the test moves.

## On your machine

Keep 0, so that you can measure the ratio when you need it.
