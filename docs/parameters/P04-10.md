## In plain words

A controller sometimes needs to know that the motor has stopped. For example, a tool changer must wait until the spindle stands still. The drive can tell it with the zero speed output. This parameter sets the speed that counts as stopped.

## How it works

The unit is rpm. When the motor speed is below this value, the drive sets the output with function 7. The factory value is 2 rpm.

A motor that holds its position still moves by tiny amounts. So the level must be a little above zero, or the output flickers.

## On your machine

This matters only if a digital output has function 7 and a controller reads it.
