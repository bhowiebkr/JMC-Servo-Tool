## In plain words

When a limit switch stops an axis, the drive can also use the dynamic brake. This stops a fast axis in a shorter distance.

## How it works

- **0**: use the dynamic brake when a limit input stops the motor.
- **1**: do not use it. This is the factory setting.

What the motor does after the stop depends on P01-10. The dynamic brake connects the motor windings together, so the turning motor brakes itself.

## On your machine

This setting matters only if the limit switches connect to the drive. Many LinuxCNC machines connect them to LinuxCNC instead.
