## In plain words

In speed mode, the motor needs some time to reach the commanded speed. The drive can tell a controller when the motor has got there, with the speed match output. This parameter sets how close counts as matched.

## How it works

The unit is rpm. When the difference between the motor speed and the command is less than this value, the drive sets the output with function 6. The factory value is 30 rpm.

## Example

A spindle runs at a command of 2000 rpm. With the factory value, the output comes on between 1970 and 2030 rpm. The controller can wait for this signal before it starts to cut.

## On your machine

This matters only if a digital output has function 6 and a controller reads it.
