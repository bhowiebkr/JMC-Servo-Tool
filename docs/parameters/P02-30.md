## In plain words

A machine needs different settings at different times. During a move, the axis must follow the path closely. At a stop, it must hold still and stay quiet. The drive can keep two complete sets of gains and change between them. This parameter selects when the drive changes from one set to the other.

## How it works

The drive has two gain sets. This parameter selects the condition that makes the drive change from gain set 1 to gain set 2. See [Gain sets](topic:gain-sets) for the parameters in each set.

When the condition becomes true, the drive changes to gain set 2. When the condition stops, the drive waits for the delay P02-33. Then it goes back to gain set 1.

The factory value is 7. The drive uses gain set 2 while a position command comes in, and gain set 1 when the command stops.

## Modes with a level

Modes 3, 4, 5, 6, 9 and 10 compare a signal with the level P02-31. The hysteresis P02-32 stops fast changes between the sets when the signal is near the level.

| Signal | Scale of P02-31 and P02-32 |
|---|---|
| Torque | 1000 = 25 % of the rated torque |
| Speed | 1000 = 200 rpm |
| Position error | 131072 = one motor turn |

## How to set it

- Use 0 to keep one gain set at all times. This is the easiest to tune.
- Use 7 for different gains during moves and at a stop. Gain set 2 is for moves, and gain set 1 is for the stop.
- Use 2 to change the set with a digital input that has function 9. Then the controller selects the set.

## On your machine

The factory mode 7 suits a CNC axis: gain set 2 while the axis moves, and gain set 1 while it stands still.

When you tune by hand, mode 0 is easier, because only gain set 1 is in use. Then you see the effect of each change, without a change of sets in between.
