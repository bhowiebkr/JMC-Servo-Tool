## In plain words

At the end of a move, the motor needs a moment to settle exactly on its target. The drive can tell a controller when this has happened, with the in-position output. This parameter selects when the drive sets that output.

## How it works

| Value | The drive sets the output when |
|---|---|
| 0 | The position error is smaller than P03-06. This can also happen during a slow move. |
| 1 | No more pulses arrive, and the position error is smaller than P03-06. This is the factory setting. |
| 2 | Like 1, but the drive also waits for the command filter P03-16 to finish. |

The position error is the distance between the commanded position and the real motor position.

## On your machine

LinuxCNC normally does not read this output. Some machines use it to check that an axis has settled before a tool change. Then keep 1, or use 2 if you use the command filter.
