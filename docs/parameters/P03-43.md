## In plain words

Each pulse has two edges: it starts with a rising edge and ends with a falling edge. The drive counts one step at one of these edges. This parameter selects which edge.

## How it works

- **0 Rising edge**: this is the factory setting.
- **1 Falling edge**

The direction signal must be stable before the counted edge. Otherwise the drive can count a step in the wrong direction.

## On your machine

The factory setting works with LinuxCNC. If an axis drifts a little each time it changes direction, the direction setup time can be too short. First increase the direction setup and hold times in LinuxCNC. Change this parameter only if that does not help.
