## In plain words

A sudden change of the position gain gives the motor a small kick. This parameter makes the change smooth, like a dimmer instead of a light switch.

## How it works

When the drive changes between the gain sets, the position loop gain moves from P02-00 to P02-01 over this time. The other gains change at once.

A change of the position gain changes the speed command for the same error. So a sudden change can make the axis jump a little.

## When to change it

The factory value of 10 ms is a good start. If you hear a click or see a mark on the work when the gains change, increase this time.
