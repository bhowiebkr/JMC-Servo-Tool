## In plain words

To speed up a heavy load, the motor needs extra torque. Without feedforward, the drive gives that torque only after the motor falls behind. Torque feedforward reads the planned acceleration and gives the torque at the same moment. It is like a cyclist who stands on the pedals as the light turns green.

## How it works

Torque feedforward adds a torque to the torque command when the speed command changes. The drive calculates it from the rate of change of the speed command, which is the commanded acceleration. 0 turns it off.

Without torque feedforward, the speed loop must see a speed error before it gives the torque for acceleration. Torque feedforward gives that torque at the start of the acceleration.

## What a change does

- A correct value reduces the following error during acceleration and deceleration.
- Too high a value causes overshoot at the start and at the end of each acceleration.
- The signal is the second difference of the position command, so it is noisy. The filter P02-20 smooths it.

## How to set it

The drive documentation does not give the scale of this value. Start with a small value and increase it in small steps. Look at the following error during acceleration.

Set the speed feedforward (P02-03) first, because it has a larger effect.

## On your machine

On a CNC machine, the following error is largest during acceleration and in tight corners. Torque feedforward helps there. Set it only when the speed feedforward (P02-03) and the load inertia ratio (P01-04) are correct.
