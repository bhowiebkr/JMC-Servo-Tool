## In plain words

A notch filter removes a band of frequencies around its center frequency P08-36. This parameter sets how wide that band is.

## How it works

The range is 0 to 20, relative to the center frequency. A higher value gives a wider notch. The factory value is 2.

- A wider notch also removes a resonance that moves a little, for example with the axis position.
- A wider notch adds more delay below the center frequency, which makes the loops less stable.

The adaptive notch P08-11 can set this value by itself. So a value that you did not set can come from the adaptive notch.

## On your machine

Start at 2. Use the narrowest notch that stops the vibration at all axis positions.
