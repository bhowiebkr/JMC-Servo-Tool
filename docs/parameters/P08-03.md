## In plain words

The drive measures the load inertia during the speed changes of a test move. This parameter sets how long each speed change takes. A short ramp is a hard push, which gives a clear measurement.

## How it works

The unit is ms. The range is 20 to 800 ms, and the factory value is 100 ms. The motor needs this time to go from zero to the speed P08-02, and again to stop.

A short ramp needs a high torque. If the torque reaches the torque limit, the measurement is wrong. A long ramp makes the motor turn further.

## On your machine

The factory value suits most machines. If the measurement fails, or the result changes a lot from test to test, try a longer ramp.
