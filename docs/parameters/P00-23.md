## In plain words

Modbus lets one master device talk to many drives on one pair of wires. Each drive has its own address, like a house number on a street. The master puts the address in each message, and only that drive answers.

## How it works

The address can be 1 to 247 in standard Modbus. Two drives with the same address on one bus answer at the same time, and both answers are lost.

## On your machine

This tool does not write this parameter. If it changed the address, it would lose its own link to the drive. If you connect several drives to one RS485 bus, set a different address on each drive from its front panel. Then set the same address in this tool.
