## What it does

A notch filter removes a narrow band of frequencies from the torque command. Use it to stop a mechanical resonance. The drive has four notch filters. Notch 1 uses P08-30, P08-31 and P08-32.

This value is the center frequency of notch 1, in Hz. 5000 turns the notch off.

## Effect

- A notch on the resonance frequency stops the vibration. Then the speed loop gain (P02-10) can go higher.
- A notch near the bandwidth of the speed loop adds delay. Then the loop becomes less stable.

## How to find the frequency

- Record the noise with a spectrum analyzer app on a phone. The resonance is the highest peak.
- Or set the adaptive notch (P08-11) to mode 1. Then read the frequency that the drive found in P08-36.

## How to set it

1. Set this value to the resonance frequency.
2. Use the factory width (P08-31) and the full depth (P08-32 = 0).
3. Increase the speed loop gain (P02-10) again.
4. If the resonance frequency changes with the axis position, use a wider notch.

Notches 2, 3 and 4 work the same way. Notch 2 uses P08-33 to P08-35. Notch 3 uses P08-36 to P08-38. Notch 4 uses P08-39 to P08-41.
