## In plain words

A small noise voltage stays around 0 V on the torque input. A dead band ignores it. The drive reads any voltage close to zero as exactly zero, so the motor does not push.

## How it works

The unit is volts. The factory value is 0 V, so there is no dead band. The drive reads a voltage between minus and plus this value as zero.

## On your machine

A CNC axis runs in position mode and does not use the analog input.
