## In plain words

The screwdriver sequence needs a signal that says "start now". This parameter selects that signal.

## How it works

- **0 Separate start input**: a change on a start input starts the sequence. The manual does not name the input function for it.
- **1 Servo on**: servo on starts the sequence. The sequence runs while servo on stays active.

## On your machine

The screwdriver sequence is for a screwdriving machine, not for a CNC axis.
