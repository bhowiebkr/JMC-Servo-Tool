## In plain words

There are many ways to home an axis. For example, the axis can move to a switch, or to a hard stop, or to the Z pulse of the encoder. This parameter selects the method for the homing function in the drive.

## How it works

The values 0 to 9 are not documented. Many drives use one value for each combination of direction, switch and Z pulse.

## On your machine

LinuxCNC does the homing itself. Keep the factory value 0.
