## In plain words

The drive can keep two complete sets of gains and change between them. This is the speed loop gain of gain set 2. Like P02-10, it sets how quickly the drive corrects a speed error.

## How it works

This is the speed loop gain of gain set 2. It works the same as P02-10, the gain of gain set 1. The drive uses gain set 2 when the gain switching condition (P02-30) is true.

In the auto-tuning modes 1 to 3 (P01-02), the drive sets this gain from the stiffness level.

## How to set it

Set it the same way as P02-10. With the factory gain switching mode 7, gain set 2 is active while a position command comes in. So tune it during moves.

## On your machine

With the factory settings, gain set 2 is active during moves. So this gain controls how stiff the axis is while it cuts.
