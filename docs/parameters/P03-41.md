## In plain words

The encoder output gives two pulse signals, A and B. The order of their edges tells the direction. This parameter swaps that order, so the device that reads the output sees the opposite direction.

## How it works

- **0 Normal**
- **1 Reversed**

This is easier than a change of the wires. It has no effect on the movement of the motor.

## On your machine

Change it only if a device reads the encoder output and counts in the wrong direction. Change it only with the servo off.
