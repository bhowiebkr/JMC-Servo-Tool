## In plain words

The drive has two pulse inputs on connector CN1. One is robust and works with many signal types. The other is very fast but needs a clean signal. This parameter selects which input the drive listens to.

## How it works

| Input | Value | Fastest pulse rate | Signal |
|---|---|---|---|
| Low-speed | 0 | 500 kHz | 5 V or 24 V differential, or open collector |
| High-speed | 1 | 4 MHz | Differential, 3.3 V to 5 V |

The pulse rate is the number of steps each second. You need it at full speed of the axis.

## Example

With 5000 pulses for each motor turn (P03-09), the motor runs at 3000 rpm. That is 50 turns each second, so the pulse rate is 50 × 5000 = 250 kHz. The low-speed input accepts this.

## On your machine

Most LinuxCNC machines use the low-speed input. Use the high-speed input only if you need more than 500 kHz and your controller has differential outputs. The wires must go to the pins of the input that you select. Change it only with the servo off.
