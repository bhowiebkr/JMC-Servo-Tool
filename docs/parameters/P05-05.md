## In plain words

A torque limit works like a slipping clutch: the motor never pushes harder than the limit. This parameter selects where the limit comes from.

## How it works

| Value | The limit comes from |
|---|---|
| 0 | The parameters P05-10 to P05-13. This is the factory setting. |
| 1 | The analog torque input. The limit is the same in both directions. |
| 2 | The parameter P05-03. |

With 0, P05-10 and P05-11 limit the torque all the time. Digital inputs can change to P05-12 and P05-13.

## On your machine

Keep 0. Then the torque limits are fixed values that noise on a wire cannot change. Change it only with the servo off.
