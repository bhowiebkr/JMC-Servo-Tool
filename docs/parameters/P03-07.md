## In plain words

The drive can report its position in two ways. It can count from zero at each power-on, like a trip counter in a car. Or it can use the full position that an absolute encoder keeps, like the total distance counter.

## How it works

- **0 Incremental**: the position counts from power-on.
- **1 Absolute, multi-turn**: the position includes the turns that a multi-turn absolute encoder counts. The encoder keeps this count with a battery when the power is off.

Format 1 is useful only with a multi-turn absolute encoder (P00-07 = 3).

## On your machine

LinuxCNC with step and direction does not read the position from the drive. It homes the machine to find its position. So this setting has no effect there. Change it only with the servo off.
