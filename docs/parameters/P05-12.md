## In plain words

Sometimes a machine needs a lower torque for a while. For example, it pushes a part against a stop, or it presses gently. A digital input can change to this lower forward limit at any time.

## How it works

The unit is percent of the rated torque. The factory value is 100 %.

When a digital input with function 7 is on, this limit replaces P05-10. When the input is off, P05-10 applies again. By default, DI5 has function 7 (see P06-09).

## On your machine

LinuxCNC can switch this input to make a soft move, for example to find a hard stop when it homes. If you do not wire the input, P05-10 applies all the time.
