## In plain words

The drive can store eight fixed speeds. Switches on three digital inputs choose one of them, so a simple machine can run at different speeds without an analog signal. This is speed 3 of the eight.

## How it works

The unit is rpm. A negative value turns the motor in reverse. The internal speeds apply only in speed mode with P04-00 = 3.

Three digital inputs, with the functions 13, 14 and 15, select the speed. Together they count in binary from 1 to 8.

| Function 13 | Function 14 | Function 15 | Speed |
|---|---|---|---|
| off | off | off | Speed 1 |
| on | off | off | Speed 2 |
| off | on | off | Speed 3 (this one) |
| on | on | off | Speed 4 |
| off | off | on | Speed 5 |
| on | off | on | Speed 6 |
| off | on | on | Speed 7 |
| on | on | on | Speed 8 |

So this speed runs when function 13 is off, function 14 is on and function 15 is off. P04-14 and P04-15 set the ramps between the speeds.

## On your machine

A CNC axis runs in position mode, so this setting has no effect there.
