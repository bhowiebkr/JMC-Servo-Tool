## In plain words

When the condition for gain set 2 ends, the drive waits a short time before it goes back to gain set 1. This stops a quick change back and forth during short pauses.

## How it works

With the factory mode 7, the drive uses gain set 2 while position commands come in. Between two moves, there can be a very short pause. Without a delay, the drive would change the gains in each pause.

The delay starts when the condition ends. If the condition comes back during the delay, the drive stays on gain set 2.

## When to change it

The factory value of 10 ms suits most machines. If the axis buzzes or clicks at the end of short moves, try a longer delay, for example 50 ms.
