## In plain words

This is how far the motor turns back at the end of the screwdriver sequence.

## How it works

The drive data lists the unit as degrees. But the range of 0 to 36000 suggests a unit of 0.01°, which makes 36000 one full turn. Check it on the machine before you rely on it.

## On your machine

The screwdriver sequence is for a screwdriving machine, not for a CNC axis.
