## In plain words

A CAN bus connects many devices on one pair of wires. Each device needs its own number, so that messages go to the correct device. The node ID is this number.

## How it works

Two devices with the same ID on one bus disturb each other, and the bus stops. The ID applies only if the drive has a CAN port and a CAN controller uses it.

## On your machine

A machine that LinuxCNC controls with step and direction does not use CAN. Leave this value as it is. This tool does not write it, because a wrong link setting can cut off a machine that uses the bus.
