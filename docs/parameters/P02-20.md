## In plain words

Acceleration is the change of speed, and speed is the change of position. So the drive must calculate the change twice to get the torque feedforward. Each small jump in the command becomes a large spike. This filter smooths the spikes, so the motor does not click or buzz when it speeds up.

## How it works

This is a low-pass filter on the torque feedforward (P02-19). The value is the time constant, in ms. 0 turns the filter off.

## What a change does

- A higher value smooths the noisy feedforward signal. The motor is quieter during acceleration.
- A higher value also delays the feedforward torque. Then it helps less at the start of an acceleration.

## How to set it

Start at the factory value, 0.80 ms. Increase it if the motor makes noise when the torque feedforward is on. It has no effect when P02-19 is 0.
