## In plain words

Electrical noise on an analog wire makes the torque command jitter. This filter smooths the signal, in the same way as the speed filter P06-41.

## How it works

The unit is ms. The factory value is 0.8 ms. A longer time removes more noise, but the torque then follows a change of the command more slowly.

## On your machine

A CNC axis runs in position mode and does not use the analog input.
