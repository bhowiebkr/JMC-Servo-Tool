## In plain words

The drive can keep two complete sets of gains and change between them. This is the PDFF factor of gain set 2. Like P02-12, it sets how softly the speed loop reacts to a change of the speed command.

## How it works

This is the PDFF factor of gain set 2. It works the same as P02-12, the factor of gain set 1. At 100 %, the speed loop of gain set 2 is a normal PI controller.

The drive uses gain set 2 when the gain switching condition (P02-30) is true. The auto-tuning modes (P01-02) do not set this value.

## On your machine

Keep it at 100 %, the same as gain set 1, unless you have a clear reason to change it.
