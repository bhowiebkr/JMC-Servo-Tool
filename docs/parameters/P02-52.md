## In plain words

A slide that stands still sticks a little. It needs a small extra push to start to move. This parameter gives the motor that extra push in the reverse direction.

## How it works

The drive adds this torque when the axis moves in reverse. It applies in position mode only. The unit is percent of the rated torque (P00-02). The friction can be different in the two directions, so the drive has a separate value for each.

## How to set it

1. Move the axis in reverse very slowly, and read the torque command on monitor item 9 (see P00-20).
2. Start with half of this torque. Increase it in small steps while you check the result.

## Watch out

Too much compensation makes the axis jump when it starts. Set the forward value P02-51 in the same way.
