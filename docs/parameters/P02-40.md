## In plain words

The speed loop normally uses PI control. The P part reacts to the error now. The I part collects the error over time. During a hard acceleration, the I part can collect too much, and the axis overshoots. This parameter turns the I part off when a signal goes above a level.

## How it works

Below the level P02-41, the speed loop uses PI control. Above the level, it uses P control only.

| Value | Signal |
|---|---|
| 0 | Torque command |
| 1 | Speed command |
| 2 | Acceleration |
| 3 | Position error |
| 4 | Off: PI control all the time |

The factory setting is 0 with a level of 10000. That is 250 % of the rated torque. So the drive uses P control only when the torque command is very high, for example in the hardest accelerations.

## When to change it

Keep the factory setting. If the axis overshoots after fast accelerations, a lower level can help.
