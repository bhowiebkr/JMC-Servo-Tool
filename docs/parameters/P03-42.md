## In plain words

The encoder output gives a Z pulse once in each motor turn. This parameter selects if the Z pulse is a high level or a low level.

## How it works

- **0 Active low**
- **1 Active high**: this is the factory setting.

The device that reads the output must expect the same level. P01-35 sets the width of the Z pulse.

## On your machine

Some machines home to the Z pulse of the motor for a very exact home position. Then the input of the controller must see the correct level. Change it only with the servo off.
