## In plain words

This is a fixed speed that you type in. In speed mode, the motor turns at this speed when the servo is on. It is a simple way to run a motor at a constant speed without any controller.

## How it works

The unit is rpm. A positive value turns the motor forward, and a negative value turns it in reverse. This applies only when P04-00 is 1. P04-14 and P04-15 set the ramps to this speed.

## On your machine

A CNC axis runs in position mode, so this setting has no effect there.
