## In plain words

In speed mode, the drive turns the motor at a commanded speed and does not care about the position. This is how a spindle or a conveyor works. This parameter selects where the speed command comes from.

## How it works

| Value | Source |
|---|---|
| 0 | An analog voltage from −10 V to +10 V. P06-40 sets the rpm for each volt. This is the factory setting. |
| 1 | A fixed speed in P04-02. |
| 2 | A field bus. |
| 3 | Eight internal speeds, P04-30 to P04-37. Three digital inputs select one of them. |

This applies only in speed mode (P01-01 = 1, or a mixed mode in speed).

## On your machine

A CNC axis runs in position mode, so this setting has no effect there. Change it only with the servo off.
