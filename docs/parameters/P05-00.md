## In plain words

In torque mode, the drive does not control the position or the speed. It controls how hard the motor pushes. Winders, presses and tensioners work this way. This parameter selects where the torque command comes from, and where the speed limit comes from.

## How it works

| Value | Torque command from | Speed limit from |
|---|---|---|
| 0 | Analog torque input | P05-02 |
| 1 | P05-03 | P05-02 |
| 2 | Analog torque input | Analog speed input |
| 3 | P05-03 | Analog speed input |

The factory setting is 0. P06-43 sets the percent of torque for each volt on the analog torque input.

A motor in torque mode with no load accelerates until something stops it. So the drive always needs a speed limit.

## On your machine

A CNC axis runs in position mode, so this setting has no effect there. Change it only with the servo off.
