## In plain words

This is the second number of the encoder output divider. P03-22 has the full explanation.

## How it works

Output lines for each turn = encoder lines × P03-23 ÷ P03-22. This value must not be larger than P03-22. The factory values 1 and 1 give the full encoder resolution.

## On your machine

If no controller reads the encoder output, these values have no effect.
