## In plain words

The drive has a small display on its front. It can show the state of the drive, or one measured value such as the speed. This parameter selects what it shows after power-on.

## How it works

- **100**: the display shows the run state. This is the normal setting.
- **Another value**: the display shows the monitor item with that number. The monitor items are called d00 to d31 on the display.

Some useful monitor items:

| Value | Shows | Unit |
|---|---|---|
| 0 | Sum of the command pulses | Pulses |
| 2 | Following error | Pulses |
| 6 | Pulse input frequency | kHz |
| 8 | Motor speed | rpm |
| 9 | Torque command | % |
| 13 | Load of the motor, last 10 seconds | % |
| 22 | Load inertia ratio, measured | % |
| 24 | Drive temperature | °C |

## On your machine

During tuning, 2 is a good choice. Then the display shows the following error while LinuxCNC moves the axis. A small and steady number means a well-tuned axis.

To check that no step pulses are lost, use 0. Move the axis a known distance and compare the sum with the number of steps that LinuxCNC sent.
