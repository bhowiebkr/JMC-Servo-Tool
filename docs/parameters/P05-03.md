## In plain words

This is a fixed torque that you type in. In torque mode, the motor pushes with this force. It can also serve as a torque limit (P05-05 = 2).

## How it works

The unit is percent of the rated torque (P00-02). A positive value pushes forward, and a negative value pushes in reverse. The range is −300 % to +300 %.

This value is the torque command when P05-00 is 1 or 3.

## Example

The rated torque is 1.27 N·m. A value of 50 % then pushes with approximately 0.64 N·m.

## On your machine

A CNC axis runs in position mode, so the command has no effect there. If P05-05 is 2, this value limits the torque in every mode.
