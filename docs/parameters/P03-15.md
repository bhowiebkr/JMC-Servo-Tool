## In plain words

The following error is the gap between where the motor should be and where it really is. A small gap is normal during a move. A large gap means that something is wrong: the axis jammed, crashed or stalled. This parameter is the largest gap that the drive allows before it stops with an alarm.

## How it works

The unit is 10 command pulses. If the following error is larger than this value × 10, the drive stops with AL.501.

The factory value is 30000, so the limit is 300000 pulses. With the factory 10000 pulses for each turn (P03-09), that is 30 motor turns. On a 5 mm ball screw, the axis could be 150 mm off before the alarm. That is far too loose for a CNC machine.

## On your machine

With step and direction, LinuxCNC cannot see the real motor position. It sends the steps and trusts the drive. So this alarm is your only protection if the axis jams or crashes. Without it, LinuxCNC continues, and the tool, the part or the machine can be damaged.

## How to set it

1. Watch the following error on the Live tab during your fastest normal moves. Use the value in pulses, not the value in encoder counts.
2. Take 2 to 3 times the largest value that you see.
3. Divide this number of pulses by 10, and set the result.

## Check the unit first

The Live tab shows the following error in two units. The row Following error is in command pulses, the unit of this parameter. The row Error (encoder) is in encoder counts. One motor turn is 10000 pulses with the factory P03-09, but 131072 counts.

The tool takes these units from JMC's list of the monitor registers. They are not yet checked on a drive. So make a test before you set this parameter:

1. Write down the position command on the Live tab.
2. Move the axis a known distance, for example 1 mm.
3. The position command must change by the number of steps for that distance.

If the change is the number of encoder counts, use the encoder value and convert it to pulses.

## Example

With 10000 pulses for each turn on a 5 mm screw, one pulse is 0.0005 mm. Your largest following error is 0.2 mm, which is 400 pulses. 2.5 × 400 = 1000 pulses, so set 100.

## Watch out

The alarm must be wired to LinuxCNC. Connect the alarm output to a fault input, so that LinuxCNC stops all axes when one drive stops.
