## In plain words

The following error is the gap between where the motor should be and where it really is. A small gap is normal during a move. A large gap means that something is wrong: the axis jammed, crashed or stalled. This parameter is the largest gap that the drive allows before it stops with an alarm.

## How it works

The unit is 10 command pulses. If the following error is larger than this value × 10, the drive stops with AL.501.

The factory value is 30000, so the limit is 300000 pulses. With 5000 pulses for each turn, that is 60 motor turns. On a 5 mm ball screw, the axis could be 300 mm off before the alarm. That is far too loose for a CNC machine.

## On your machine

With step and direction, LinuxCNC cannot see the real motor position. It sends the steps and trusts the drive. So this alarm is your only protection if the axis jams or crashes. Without it, LinuxCNC continues, and the tool, the part or the machine can be damaged.

## How to set it

1. Watch the following error on the Live tab during your fastest normal moves.
2. Take 2 to 3 times the largest value that you see.
3. Divide this number of pulses by 10, and set the result.

## Example

With 5000 pulses for each turn on a 5 mm screw, one pulse is 0.001 mm. Your largest following error is 0.2 mm, which is 200 pulses. 2.5 × 200 = 500 pulses, so set 50.

## Watch out

The alarm must be wired to LinuxCNC. Connect the alarm output to a fault input, so that LinuxCNC stops all axes when one drive stops.
