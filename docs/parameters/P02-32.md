## In plain words

If a signal moves up and down near the switching level, the drive could change between the gain sets many times each second. The hysteresis is a band around the level that stops this chatter.

## How it works

A home thermostat works the same way. It turns the heating on at 20 °C, but off only at 21 °C. Without this band, the heating would click on and off all the time.

The drive changes to gain set 2 when the signal goes above the level P02-31. It goes back only when the signal falls clearly below the level. The width of the band is this value, in the same unit as P02-31.

## When to change it

With the factory mode 7, this value has no effect. If you use a mode with a level and the sound of the motor changes often, increase the hysteresis.
