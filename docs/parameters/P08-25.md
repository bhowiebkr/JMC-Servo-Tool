## What it does

The disturbance observer estimates the outside torque on the motor. Examples are cutting forces and friction. The drive adds a torque to cancel part of it. This value sets how much of the estimated torque the drive cancels, in %. 0 turns the observer off.

The observer compares the torque command with the acceleration of the motor. For this, it needs the correct load inertia ratio (P01-04).

## Effect

- A higher value holds the position better against cutting forces and friction.
- A higher value also adds noise to the torque command. The filter P08-26 reduces this noise.
- A wrong load inertia ratio gives a wrong estimate, and the observer can cause vibration.

## How to set it

1. Set the load inertia ratio (P01-04) and the speed loop first.
2. Increase this value in steps of 10 %.
3. Look at the position error on the Live tab when the load changes.
4. Stop when the motor makes noise. Then go back one step.
