## In plain words

Inside the drive, a speed loop compares the speed that the motor should have with the speed that it really has. Then it changes the motor torque to correct the difference. This gain sets how quickly it corrects. It is like a driver who holds a steady speed on a hill, and does not wait for the speed to drop.

## How it works

The speed loop gain sets how strongly the drive corrects the speed error. The speed error is the difference between the speed command and the measured speed. The speed loop makes the torque command from it.

The unit is Hz. When the load inertia ratio (P01-04) is correct, this value is the bandwidth of the speed loop. The bandwidth is the highest command frequency that the loop follows well.

## What a change does

- A higher gain gives a stiffer axis. A cutting force pushes the motor less far from its position.
- A higher gain also lets you set a higher position loop gain (P02-00).
- Too high a gain causes vibration and a high-pitched noise. It can start a mechanical resonance.
- Filters (P08-19, P08-20) add delay. With more delay, the loop becomes unstable at a lower gain.

## How to set it

1. Set the load inertia ratio (P01-04) first. Set the auto-tuning mode (P01-02) to 0.
2. Set the position loop gain (P02-00) low for this test.
3. Increase the speed loop gain in steps of approximately 10 %. Run moves and listen to the motor.
4. Stop when the motor makes noise or vibrates. Decrease the gain to 70 to 80 % of that value.
5. Then set the integral time (P02-11) and the position loop gain (P02-00).

If a resonance limits the gain, a notch filter (P08-30) can remove it. Then the gain can go higher.

## On your machine

The speed loop is what resists the cutting force. When the tool bites, the motor slows a little, and the speed loop pushes back. A higher gain gives a stiffer axis and a better surface. The limit is usually noise or vibration from the frame.
