## In plain words

During homing, the axis starts, stops and turns around several times. This parameter sets how gently it changes speed.

## How it works

The factory value is 0, which probably means the fastest possible change. The unit is not documented. It is probably ms.

## On your machine

This applies only to the homing function in the drive. LinuxCNC does the homing itself, so this setting has no effect there.
