## What it does

This is a low-pass filter on the output of the disturbance observer (P08-25). The value is the time constant, in ms.

## Effect

- A higher value gives less noise from the observer.
- A higher value also makes the observer react more slowly to a load change. Then the compensation is weaker.

## How to set it

Start at the factory value, 0.80 ms. Increase it if the motor makes noise with the observer on. It has no effect when P08-25 is 0.
