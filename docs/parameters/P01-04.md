## What it does

The load inertia ratio is the inertia of the load divided by the inertia of the motor rotor (P00-04). The load includes the coupling, the screw and all parts that move with the axis.

The drive uses this ratio to scale the speed loop. With the correct ratio, the speed loop gain (P02-10) is a true bandwidth in Hz. A ratio of 3.0 means that the load inertia is three times the rotor inertia.

## Effect

The real speed loop gain is the set gain multiplied by (1 + set ratio) ÷ (1 + real ratio).

- A ratio that is too low makes the real gain lower than the set gain. The motor feels soft, and the following error is large.
- A ratio that is too high makes the real gain higher than the set gain. The motor can vibrate or make noise.

The drawing takes the value in the drive or file as the real ratio. A trial value shows what happens when the set ratio is wrong.

## How to get the ratio

- Use the offline inertia identification of the drive (panel function AF-J-L). P08-02 to P08-05 set its speed, ramp time, wait time and number of turns. Then write the result to this parameter.
- The motor turns during the identification. Make sure that the axis has space to move in both directions.
- Or calculate the ratio from the machine data. For a ball screw, the load inertia is m × (p ÷ 2π)² + J screw + J coupling. Here m is the moving mass in kg and p is the screw lead in m.
