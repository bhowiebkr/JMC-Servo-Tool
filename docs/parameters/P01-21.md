## In plain words

A turning motor that loses its power coasts until friction stops it. A dynamic brake stops it faster. It connects the motor windings together, so the motor works as a generator against itself. A bicycle dynamo feels harder to turn when the lamp is on, for the same reason.

## How it works

This parameter selects if the drive uses the dynamic brake when the main power goes off.

- **0**: use the dynamic brake.
- **1**: do not use it. The motor coasts. This is the factory setting.

Note the reversed logic: 0 means yes.

The dynamic brake slows the motor, but it does not hold it. The braking force falls with the speed and is zero at a stop. Use a holding brake to hold a vertical axis.

## On your machine

If the power fails while an axis moves fast, a dynamic brake shortens the distance that it coasts. This can protect the machine. Frequent use at high speed can overload the brake circuit, and then the drive stops with AL.436.
