## In plain words

An analog speed command uses the sign of the voltage for the direction. A positive voltage turns the motor one way, and a negative voltage turns it the other way. This parameter turns that direction around.

## How it works

- **0 Normal**: a positive voltage turns the motor forward.
- **1 Reversed**: a positive voltage turns the motor in reverse.

This applies only when the speed command is analog (P04-00 = 0).

## On your machine

A CNC axis in position mode does not use the analog input. Change it only with the servo off.
