## In plain words

Homing has two speeds. First the axis moves fast to find the home switch. Then it moves slowly to find the exact point. This parameter is the fast speed.

## How it works

The factory value is 100. The unit is not documented. It is probably rpm.

## On your machine

This applies only to the homing function in the drive. LinuxCNC does the homing itself, so this setting has no effect there.
