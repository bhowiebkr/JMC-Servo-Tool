## In plain words

A digital input is a wire from a switch, a sensor or a controller. The signal on it is either on or off. This parameter decides which signal on DI2 counts as active. While the input is active, its function is on.

The function of DI2 is P06-03. Its factory function is alarm reset.

## How it works

Each input goes through an optocoupler. That is a small LED and a light sensor in one package. When current flows through the LED, the optocoupler is on. The manual calls this state low, and the other state high.

| Value | The function is on |
|---|---|
| 0 | While the optocoupler is on, so while current flows. This is the factory setting. |
| 1 | While the optocoupler is off, so while no current flows. |
| 2 | Once, at a rising edge, when the signal changes from low to high. |
| 3 | Once, at a falling edge, when the signal changes from high to low. |
| 4 | Once, at each change. |

A level (0 or 1) suits a function that must last, like servo on or a limit. An edge (2, 3 or 4) suits a function that happens once, like homing start.

The change takes effect after a power cycle. Save it to EEPROM, then turn the drive off and on.

## Watch out

With 1, an input with no wire is always active. For example, servo on with 1 turns the servo on at power-on, with nothing connected.

## On your machine

Keep 0. An edge (2 or 3) also suits alarm reset, because a reset happens once.
