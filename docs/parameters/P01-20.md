## In plain words

When a brake condition comes, the drive can wait a short time before it starts the dynamic brake. This parameter sets that wait time.

## How it works

The dynamic brake connects the motor windings together, so the turning motor brakes itself. P01-21 to P01-24 select when the drive uses it. This delay is the time from the brake condition to the start of the braking.

The manual of this drive gives a range up to 150 ms. The drive table allows up to 250 ms.

## On your machine

The delay applies only if one of P01-21 to P01-24 is 0 (use the dynamic brake). By default, all four are 1, so the delay has no effect. Keep the factory value of 50 ms if you turn on the dynamic brake.
