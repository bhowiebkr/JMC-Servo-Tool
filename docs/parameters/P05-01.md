## In plain words

An analog torque command uses the sign of the voltage for the direction. This parameter turns that direction around, so a positive voltage pushes the other way.

## How it works

- **0 Normal**
- **1 Reversed**

This applies only when the torque command is analog (P05-00 = 0 or 2).

## On your machine

A CNC axis runs in position mode, so this setting has no effect there. Change it only with the servo off.
