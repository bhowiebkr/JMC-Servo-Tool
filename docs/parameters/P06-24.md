## In plain words

A digital output is an electronic switch inside the drive. A controller or a relay reads it. This parameter decides if the switch conducts or blocks when the function of DO3 is active.

The function of DO3 is P06-25. Its factory function is alarm.

## How it works

Each output is an optocoupler. When it is on, current can flow through the output.

- **0**: the optocoupler is off while the function is active.
- **1**: the optocoupler is on while the function is active. This is the factory setting.

The change takes effect after a power cycle. Save it to EEPROM, then turn the drive off and on.

## Watch out

A relay coil on an output needs a diode across the coil. Without it, a voltage spike when the relay opens can damage the output. The +24 V supply on CN1 gives no more than 150 mA in total.

## On your machine

Think about the alarm output carefully. With 1, current flows only at an alarm. A drive with no power, or a broken wire, then looks like a drive with no alarm. With 0, current flows while all is well, and any fault stops it. If you change it, also invert the fault input in LinuxCNC.
