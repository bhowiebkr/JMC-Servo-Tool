## In plain words

The drive has five digital outputs, DO1 to DO5. They tell the controller what the drive is doing. You give each output a job, its function, from the list below. This parameter sets the function of DO2. The factory function is holding brake release.

## How it works

P06-22 sets if the output conducts or blocks while its function is active.

| Value | Function | What it does |
|---|---|---|
| 0 | Not used | The output is never active. |
| 1 | Alarm | Active when the drive has stopped with an alarm. |
| 2 | Holding brake release | Active when the holding brake in the motor must open. P01-30 sets the timing. |

This output accepts only the functions 0 to 2.

The change takes effect after a power cycle. Save it to EEPROM, then turn the drive off and on.

## On your machine

This output switches the holding brake of the motor through a relay. A motor without a brake does not need it. Normally only a vertical Z axis has a brake.
