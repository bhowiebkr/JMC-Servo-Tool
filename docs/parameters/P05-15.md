## In plain words

A normal screw tightens clockwise, but a left-hand thread tightens the other way. This parameter selects the direction in which the screwdriver sequence turns.

## How it works

The factory value is 1. The drive data does not say which direction each value gives. Test it with the screw removed.

## On your machine

The screwdriver sequence is for a screwdriving machine, not for a CNC axis.
