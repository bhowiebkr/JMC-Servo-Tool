## In plain words

After each test move, the drive waits for a moment before the next move. The wait lets the machine settle, so that a vibration does not spoil the next measurement.

## How it works

The unit is ms. The range is 50 to 10 000 ms, and the factory value is 1000 ms.

## On your machine

The factory value suits most machines. A machine that vibrates for a long time after a stop needs a longer wait.
