## In plain words

This is the most a motor can push in the reverse direction. It works like a slipping clutch, in the same way as the forward limit P05-10.

## How it works

The unit is percent of the rated torque, and the value is negative. The factory value is −200 %.

This limit applies all the time, in every mode. A digital input with function 8 changes to the lower limit P05-13.

## On your machine

Normally, set the same size as the forward limit, with a minus sign. A vertical axis is the exception. There gravity helps one direction and works against the other. So the two directions can need different limits.
