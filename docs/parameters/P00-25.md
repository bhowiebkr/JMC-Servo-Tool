## In plain words

Each character on a serial line has a frame around it. The parity bit is a simple check that finds some errors. The stop bits mark the end of each character. All devices on the line must use the same frame.

## How it works

- **Even or odd parity**: the sender adds one bit. Then the number of 1 bits in each character is always even, or always odd. The receiver checks this.
- **Stop bits**: one or two idle bits at the end of each character.

Standard Modbus uses even parity with 1 stop bit. Without parity, the standard asks for 2 stop bits.

## On your machine

This tool does not write this parameter, because a wrong format cuts off the link. Change it on the front panel if you need to. Then set the same format in this tool.
