## In plain words

The speed loop calculates a new torque command thousands of times each second. That command contains fast wiggles, and the motor turns them into noise. This filter removes the fast wiggles and keeps the slow, useful part. Too much filtering adds delay, and delay makes the loop unstable.

## How it works

This is a low-pass filter on the torque command. It sits between the speed loop and the current loop. The value is the time constant of the filter, in ms.

The filter removes high frequencies from the torque command. The corner frequency is 1 ÷ (2π × time constant). At 0.80 ms, the corner frequency is approximately 200 Hz.

## What a change does

- A higher value removes more high-frequency noise. The motor is quieter.
- A higher value also adds delay to the speed loop. Then the speed loop gain (P02-10) must be lower.

## How to set it

1. Start at the factory value, 0.80 ms.
2. If the motor makes a high-pitched noise, increase the value in steps of 0.1 ms.
3. Stop at the lowest value that removes the noise.

If the noise has one clear frequency, a notch filter (P08-30) is better. A notch removes that frequency with less delay.

In the auto-tuning modes 1 and 2 (P01-02), the drive sets this value from the stiffness level. In mode 3, the drive sets it from the load inertia ratio (P01-04).

The drive uses P08-21 in place of this filter at low speed.

## On your machine

This filter is often the first tool against a high-pitched whine. If the whine has one clear pitch, a notch filter (P08-30) removes it with less delay.
