## In plain words

If the home switch is broken, the axis could search for it forever. This time limit stops the search with an alarm.

## How it works

If homing takes longer than this time, the drive stops with AL.551. The factory value is 0, which probably means no limit. The unit is not documented.

## On your machine

This applies only to the homing function in the drive. LinuxCNC does the homing itself, so this setting has no effect there.
