## In plain words

This is the top speed that the drive allows in the forward direction. It is like a speed limiter in a car.

## How it works

The unit is rpm. The factory value is 5000 rpm. The manual lists this limit with the speed mode settings. It does not say if it also applies in position mode.

The reverse direction has its own limit, P04-07.

## On your machine

In position mode, LinuxCNC sets the speed with its maximum velocity. Keep this limit above the fastest speed that LinuxCNC commands. If the drive limits the speed in position mode, the axis falls behind, and the following error grows.
