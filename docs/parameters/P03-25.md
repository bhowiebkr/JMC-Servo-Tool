## In plain words

An absolute encoder does not send pulses. It sends its position as numbers. To serve a controller that counts pulses, the drive makes A and B pulses from the encoder position. This parameter sets how many pulses it makes for each motor turn.

## How it works

The value is the number of pulses on each of the A and B outputs in one turn. A controller that counts all edges of A and B sees 4 times this number. So the factory value of 2500 gives 10000 counts for each turn.

The output must not go faster than the drive can make pulses. A high value at a high speed gives the alarm AL.500.

## On your machine

LinuxCNC with step and direction does not read the encoder output. If you use it, for example to show the real position, set a value that your encoder input can count at full speed.
