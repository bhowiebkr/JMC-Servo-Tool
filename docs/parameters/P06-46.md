## In plain words

Even with a good offset, a small noise voltage stays around 0 V. A dead band ignores it. The drive reads any voltage close to zero as exactly zero, so the motor stands still.

## How it works

The unit is volts. The factory value is 0 V, so there is no dead band. The drive reads a voltage between minus and plus this value as zero.

## Example

With 0.05 V, the drive reads any voltage from −0.05 V to +0.05 V as zero. At 300 rpm for each volt, this hides a creep of up to 15 rpm.

## On your machine

A CNC axis runs in position mode and does not use the analog input. Keep the dead band small. A large dead band makes slow speeds impossible.
