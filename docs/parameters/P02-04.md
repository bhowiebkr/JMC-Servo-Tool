## What it does

This is a low-pass filter on the speed feedforward (P02-03). The value is the time constant of the filter, in ms. 0 turns the filter off.

The position command arrives as pulses. So the command rate changes in small steps, and the feedforward signal is rough. The filter smooths it before it goes to the speed loop.

## Effect

- A higher value gives a smoother feedforward signal and quieter motion.
- A higher value also delays the feedforward. During acceleration, the following error becomes larger.
- At 0, all of the roughness of the command goes to the speed loop.

## How to set it

Start at the factory value, 0.50 ms. Increase it if the motor is noisy at constant speed with feedforward on. Keep it small, because the delay works against the feedforward.

In the auto-tuning mode 2 (P01-02), the drive fixes this value at 0.50 ms.
