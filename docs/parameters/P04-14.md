## In plain words

A sudden jump in speed gives a jolt to the machine and a high current to the motor. A ramp changes the speed smoothly instead. This parameter sets how fast the motor speeds up in speed mode.

## How it works

The unit is milliseconds for each 1000 rpm. 0 gives no ramp: the motor accelerates as fast as it can.

## Example

With 200, the motor needs 200 ms for each 1000 rpm. So it takes 600 ms to accelerate from 0 to 3000 rpm.

## On your machine

This applies in speed mode only. In position mode, LinuxCNC plans the acceleration with its own settings.
