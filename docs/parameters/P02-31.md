## In plain words

Some gain switching modes compare a signal with a level. Above the level, the drive uses gain set 2. This parameter is that level.

## How it works

The unit depends on the mode in P02-30.

| Mode in P02-30 | Signal | Scale |
|---|---|---|
| 3 | Torque command | 1000 = 25 % of rated torque |
| 4, 5, 9, 10 | Speed or change of speed | 1000 = 200 rpm |
| 6 | Position error | 131072 = one motor turn |

For example, the factory value 800 means 20 % torque, 160 rpm, or approximately 2.2° of position error.

The modes 0, 1, 2, 7 and 8 do not use the level.

## When to change it

With the factory mode 7, this value has no effect. Set it only if you select a mode that uses a level.
