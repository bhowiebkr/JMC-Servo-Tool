## In plain words

An analog wire picks up electrical noise from motors and cables. The noise makes the speed command jitter, so the motor does not run smoothly. This filter smooths the signal.

## How it works

The unit is ms. The factory value is 0.8 ms. A longer time removes more noise, but the motor then reacts more slowly to a change of the command.

The filter is a low-pass filter. After a step of the voltage, the filtered value reaches approximately 63 % of the step in this time.

## On your machine

A CNC axis runs in position mode and does not use the analog input. If a motor in speed mode hunts or hums at a constant command, a slightly longer filter can help. Also check that the analog cable is shielded.
