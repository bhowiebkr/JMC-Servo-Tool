## In plain words

A little vibration is always present while a motor runs. The adaptive notch (P08-11) must decide which vibration is a real resonance. This parameter sets how large a vibration must be before the adaptive notch acts on it.

## How it works

This sets the vibration level at which the adaptive notch (P08-11) operates. The range is 1 to 7.

## What a change does

- A lower value detects smaller vibration.
- Too low a value makes the adaptive notch react to normal motion. Then it can set a notch where there is no resonance.

## How to set it

Start at the factory value, 4. Decrease it if the adaptive notch does not find a vibration that you can hear. It has no effect when P08-11 is 0.
