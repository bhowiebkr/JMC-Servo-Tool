## In plain words

A slide that stands still sticks a little. It needs a small extra push to start to move. This is static friction. This parameter gives the motor that extra push in the forward direction.

## How it works

The drive adds this torque when the axis moves forward. It applies in position mode only. The unit is percent of the rated torque (P00-02).

Without compensation, static friction makes small errors when the axis starts or changes direction. On a milled circle, this shows as small flat spots or bumps where an axis reverses.

## How to set it

1. Move the axis forward very slowly, and read the torque command on monitor item 9 (see P00-20).
2. Start with half of this torque. Increase it in small steps while you check the result.

## Watch out

Too much compensation makes the axis jump forward when it starts. Set the reverse value P02-52 in the same way.
