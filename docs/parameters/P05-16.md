## In plain words

A screw that is cross-threaded or missing can make the sequence run on and on. This time limit is an extra check that stops it.

## How it works

The unit is seconds. The factory value is 10 s. If the whole sequence takes longer than this time, the drive ends it.

## On your machine

The screwdriver sequence is for a screwdriving machine, not for a CNC axis.
