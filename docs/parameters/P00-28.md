## In plain words

A Modbus device keeps its values in numbered registers. The register map is the list that says which value is in which register. This parameter selects one of the maps that the drive knows.

## How it works

- **1**: the standard map of this drive.
- **2**: a map that is compatible with another brand of controller. It adds two registers.

The parameter registers that this tool uses do not depend on this setting.

## On your machine

Use 1 unless a controller needs the other map. A change applies after a power cycle.
