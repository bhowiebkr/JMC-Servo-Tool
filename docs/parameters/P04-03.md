## In plain words

An analog speed signal is never exactly 0 V. A tiny voltage remains, and the motor creeps slowly when it should stand still. The zero clamp stops this. It locks the motor at its position when the speed command is almost zero.

## How it works

In speed mode, the drive locks the motor position when all three of these are true:

1. This parameter is 1.
2. The speed command is smaller than P04-04.
3. A digital input with function 10 is on.

While the clamp is on, the motor holds its position like an axis in position mode.

## On your machine

A CNC axis runs in position mode, so this setting has no effect there.
