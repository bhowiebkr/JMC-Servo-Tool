## In plain words

The drive can repeat its encoder position on connector CN1 as A and B pulses. Another controller can count these pulses to know where the motor is. With an incremental encoder, this divider can reduce the number of pulses for each turn, if the other controller cannot count fast enough.

## How it works

The number of output lines for each turn is:

encoder lines × P03-23 ÷ P03-22

P03-23 must not be larger than P03-22. The drive can reduce the pulse count, but not increase it.

## Example

The encoder has 2500 lines, and the controller needs 500 lines for each turn. 500 ÷ 2500 = 1 ÷ 5. Set this parameter to 5 and P03-23 to 1.

## Watch out

A wrong setting gives the alarm AL.106. This divider applies to incremental encoders. For an absolute encoder, use P03-25.
