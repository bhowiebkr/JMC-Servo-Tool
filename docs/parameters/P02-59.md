## In plain words

The current loop is the innermost control loop. It makes the motor current that gives the torque. The factory sets its gains. Different firmware versions store these gains in different formats. This parameter tells the drive which format the stored gains use.

## How it works

- **0**: the old format of firmware V4.x to V6.x.
- **1**: the new current loop format.

A parameter file from an older drive uses the old format. With the wrong format, the drive reads the current loop gains wrongly.

## When to change it

Do not change it. If you load a parameter file from a different firmware version, keep the value that the file gives.
