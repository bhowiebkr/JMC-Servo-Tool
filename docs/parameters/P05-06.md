## In plain words

The drive can tell a controller when the motor pushes at its torque limit, with the torque limit output. During a hard acceleration, the motor can touch the limit for a moment, which is normal. This delay stops the output for such short moments.

## How it works

The unit is ms. The drive sets the output with function 8 only if the motor stays at the limit for this time. The factory value is 0, so the output comes on at once.

By default, DO5 has function 8 (see P06-29).

## On your machine

If LinuxCNC reads the torque limit output, a delay of 50 to 100 ms stops false signals during fast moves. A real jam keeps the motor at the limit for longer.
