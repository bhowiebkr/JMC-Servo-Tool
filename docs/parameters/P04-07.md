## In plain words

This is the top speed that the drive allows in the reverse direction. It is like a speed limiter in a car.

## How it works

The unit is rpm, and the value is negative. The factory value is −5000 rpm. The manual lists this limit with the speed mode settings. It does not say if it also applies in position mode.

The forward direction has its own limit, P04-06.

## On your machine

Keep this limit beyond the fastest reverse speed that LinuxCNC commands. Remember the minus sign.
