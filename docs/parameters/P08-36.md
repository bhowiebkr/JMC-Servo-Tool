## In plain words

Every machine part has a frequency at which it likes to vibrate, like a guitar string. If the drive pushes at that frequency, the vibration grows, and the motor hums or whines. A notch filter removes that one frequency from the torque command and leaves the rest. The drive has four notch filters. This is the frequency of notch 3.

## How it works

The unit is Hz, and the range is 50 to 5000 Hz. 5000 turns the notch off. This is the factory value.

Notch 3 uses P08-36 for the frequency, P08-37 for the width and P08-38 for the depth.

The adaptive notch P08-11 can set this value by itself. So a value that you did not set can come from the adaptive notch.

## How to find the frequency

- Record the noise with a spectrum analyzer app on a phone. The resonance is the highest peak.
- Or let the adaptive notch P08-11 find it. It writes the frequency into notch 3.

## On your machine

Use another notch when a machine has more than one resonance, for example the gantry and the ball screw. Notch 1 (P08-30) explains the full procedure. If the adaptive notch is on, it can change this value. For a notch that you set by hand, use notch 1 or notch 2.
