## In plain words

The resistance of a braking resistor, in ohms, sets how fast it can take energy. A lower resistance takes more current, so it absorbs energy faster.

## How it works

The drive uses this value to calculate the power in the resistor. Each drive has a lowest allowed resistance. A lower resistance lets too much current through the braking switch of the drive and can damage it. The data sheet of the drive gives this lowest value.

## On your machine

This value applies only with an external resistor (P00-30 = 1). Set it from the label of the resistor. Measure the resistor with a meter if you are not sure.
