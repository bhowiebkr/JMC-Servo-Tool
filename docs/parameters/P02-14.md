## What it does

This is the speed loop integral time of gain set 2. It works the same as P02-11, the integral time of gain set 1.

The factory value is 1000.0 ms. This gives almost no integral action in gain set 2. With the factory gain switching mode 7, the drive uses gain set 2 during moves. So the integral action is strong at a stop (P02-11) and weak during moves.

## Effect

- A shorter time removes speed error faster during moves.
- Too short a time causes overshoot at the end of a move.

In the auto-tuning modes 1 and 2 (P01-02), the drive sets this value from the stiffness level. In mode 3, it is fixed at 100.
