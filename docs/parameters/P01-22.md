## In plain words

At servo off, the drive takes the current away from the motor. A turning motor then coasts. This parameter selects if the drive uses the dynamic brake to stop the motor faster.

## How it works

- **0**: use the dynamic brake at servo off.
- **1**: do not use it. The motor coasts. This is the factory setting.

The dynamic brake connects the motor windings together, so the turning motor brakes itself. It does not hold the motor at a stop.

## On your machine

LinuxCNC normally turns the servo off only when the axis stands still, so this setting rarely matters. If an emergency stop removes the servo on signal during a fast move, a dynamic brake stops the axis in a shorter distance.
