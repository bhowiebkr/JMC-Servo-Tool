## What it does

This is a low-pass filter on the position command. The value is the time constant of the filter, in ms. 0 turns the filter off.

The filter smooths the steps in the command. Starts and stops become softer.

## Effect

- A higher value gives smoother starts and stops.
- The motor follows the command with a delay of approximately one time constant.
- At the end of a move, the motor settles approximately three time constants after the command stops.

## On a CNC machine

A CNC controller, for example LinuxCNC, already plans smooth motion with acceleration limits. So keep this filter at 0 or small.

On a machine with several axes, use the same value on all axes that move together. A different delay on each axis changes the shape of curves and corners. At high speed, a circle becomes an ellipse.
