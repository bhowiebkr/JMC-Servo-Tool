## In plain words

The drive can store a second gear ratio. A digital input then changes between the two ratios. This parameter is the top number of the second ratio.

## How it works

A digital input with function 6 selects gear 2. When the input is off, the drive uses gear 1 (P03-10 ÷ P03-11). When it is on, the drive uses this numerator divided by P03-14.

A second ratio is useful if the same axis needs a fine mode and a fast mode. Change between the ratios only when the motor stands still.

## On your machine

LinuxCNC does not need a second gear ratio. Keep the factory value 1.
