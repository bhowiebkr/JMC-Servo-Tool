## In plain words

This is a lower torque limit in the reverse direction. A digital input can change to it at any time, in the same way as the forward limit P05-12.

## How it works

The unit is percent of the rated torque, and the value is negative. The factory value is −100 %.

When a digital input with function 8 is on, this limit replaces P05-11. By default, DI6 has function 8 (see P06-11).

## On your machine

If you do not wire the input, P05-11 applies all the time.
